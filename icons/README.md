# Package icons

Optional. Catalog `icon` may be:

- a full `https://…` URL, or
- a repo-relative path (e.g. `icons/blender.png`)

Packages **without** `icon` use the app’s generic fallback tile.

Current:

| Package | Source |
|---------|--------|
| blender | Pinterest Blender mark (also mirrored as `blender.png`) |
| box64 | SourceForge project icon (also mirrored as `box64.png`) |
| others | no icon field → app fallback |
